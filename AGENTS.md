# Agent Rules

2) If instructions conflict: PROJECT_STATE.md > repo files > chat.
3) Never invent file paths. If unsure, search the repo.
4) When a change spans >2 files:

   - list files you will touch
   - then execute
5) After major work, update PROJECT_STATE.md and TODO.md.
6) After work always run the tests
